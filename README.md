# 欧宝坦克大战 OUBAO TANKS

本地多人坦克对战游戏，纯 HTML5/Canvas/JS 实现，零外部依赖。

> 📋 开发计划与路线图请参见 [DEVPLAN.md](DEVPLAN.md)

## 项目愿景

让孩子在游戏互动中将书本上的坦克知识（装甲厚度、主炮口径、战术协同等）具象化，在「玩中学、学中用」，打造充满成就感的亲子家庭对战游戏。

**设计原则：**
- **真实性与趣味性平衡**：引入弱点攻击、跳弹、吨位差异，但保持街机般的爽快手感
- **低门槛亲子配合**：分工明确的协作机制（一人驾驶、一人炮塔瞄准），降低低龄儿童操作负荷
- **知识正向激励**：通过对战胜场解锁真实坦克百科图鉴，激发阅读与探索欲
- **保护眼睛与自制力**：快节奏设计（单局3-5分钟），内置游戏时长防沉迷提示

## 快速开始

直接用浏览器打开 `index.html` 即可游玩。

## 游戏模式

| 模式 | 按键 | 说明 |
|------|------|------|
| 单人对战 | `1` | 玩家 vs AI（可调难度和数量） |
| 双人对战 | `2` | 本地双人对战 |
| 协作对战 | `3` | 2人组队 vs AI |
| 基地保卫战 | `4` | 守护基地，摧毁敌方基地获胜 |
| 护送装甲车 | `5` | 护送运输车到撤离点获胜 |

## 操作方式

| | 玩家1 | 玩家2 |
|---|---|---|
| 移动 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| 开火 | `F` / `空格` | `L` / `回车` |
| 暂停 | `P` / `Esc` | `P` / `Esc` |
| 静音 | `M` | `M` |

## 游戏设置（主菜单）

- `←` `→` 选择地图（12张）
- `C` / `V` 切换车型（轻/中/重/突击炮）
- `Q` 切换AI难度（简单/普通/困难）
- `Z` `X` 调整AI数量（1-10）
- `回车` / `空格` 开始游戏

## 游戏规则

- 先胜 **5局** 获得最终胜利
- 砖墙可被子弹摧毁，钢墙无敌
- 水面阻挡坦克通行，草丛隐藏坦克
- 每隔5-8秒随机刷新道具，场上最多3个

## 技术架构

### 技术栈

| 层面 | 技术 |
|------|------|
| 渲染 | HTML5 Canvas 2D |
| 音效 | Web Audio API（程序化生成） |
| 输入 | 键盘事件监听（支持双人） |
| 构建 | 无构建工具，直接 `<script>` 标签加载 |
| 兼容性 | Chrome/Firefox/Safari/Edge |

### 文件结构

```
js/
├── utils.js              常量、工具函数、CONFIG配置（20个可调参数）

├── maps.js               12张地图定义（水平镜像对称）
```

### 画布参数

- 逻辑分辨率：1600×900（16:9）

### CONFIG 配置对象

游戏参数集中在 `utils.js` 的 `CONFIG` 对象中，调整平衡性只需修改一处：

```js
const CONFIG = {
  BULLET_HIT_RANGE: 26,        // 子弹碰撞判定范围
  POWERUP_PICKUP_RANGE: 34,    // 道具拾取范围
  POWERUP_DURATION: 8,         // 增益道具持续时间
  HEAL_AMOUNT: 40,             // 维修回血量
  MEGA_HP_BONUS: 50,           // 巨型额外血量
  MINE_DAMAGE: 50,             // 地雷伤害
  AI_DODGE_RANGE: 80,          // AI躲避子弹范围
  AI_SEEK_RANGE: 200,          // AI搜寻道具范围
  WIN_ROUNDS: 5,               // 胜利局数
  // ... 共20个参数
};
```

### 游戏状态机

```
menu → countdown → play → round → (match | countdown)
                    ↓        ↓
                  pause    menu
```

| 状态 | 说明 | 可触发的转换 |
|------|------|--------------|
| menu | 主菜单 | → countdown（按回车） |
| countdown | 3-2-1倒计时 | → play |
| play | 游戏进行中 | → round（回合结束）、→ pause |
| round | 回合结算横幅 | → countdown（下回合）、→ match（胜利） |
| match | 最终胜利画面 | → menu（Esc）、→ countdown（R重来） |
| pause | 暂停 | → play（P继续）、→ menu（Esc） |
