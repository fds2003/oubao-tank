# 欧宝坦克大战 OUBAO TANKS

本地多人坦克对战游戏，纯HTML5/Canvas/JS实现，无任何依赖。

> 📋 详细需求文档请参见 [REQUIREMENTS.md](REQUIREMENTS.md)
> 📝 开发计划请参见 [DEVPLAN.md](DEVPLAN.md)

## 快速开始

直接用浏览器打开 `index.html` 即可游玩。

## 游戏模式

| 模式 | 按键 | 说明 |
|------|------|------|
| 单人对战 | `1` | 玩家 vs AI（可调难度和数量） |
| 双人对战 | `2` | 本地双人对战 |
| 协作对战 | `3` | 2人组队 vs AI |

## 操作方式

| | 玩家1 | 玩家2 |
|---|---|---|
| 移动 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| 开火 | `F` / `空格` | `L` / `回车` |
| 暂停 | `P` / `Esc` | `P` / `Esc` |
| 静音 | `M` | `M` |

## 游戏设置（主菜单）

- `←` `→` 选择地图（12张）
- `Q` 切换AI难度（简单/普通/困难）
- `Z` `X` 调整AI数量（1-10）
- `回车` / `空格` 开始游戏

## 游戏规则

- 先胜 **5局** 获得最终胜利
- 砖墙可被子弹摧毁，钢墙无敌
- 水面阻挡坦克通行，草丛隐藏坦克
- 每隔5-8秒随机刷新道具，场上最多3个

## 道具系统（11种）

| 道具 | 效果 | 持续 |
|------|------|------|
| 护盾 |抵挡一次伤害 | 8秒 |
| 疾速 |移动速度+50% | 8秒 |
| 维修 |恢复40HP | 瞬间 |
| 连发 |冷却缩短+上限4发 | 8秒 |
| 冰冻 |冻结所有敌人（随敌人数衰减） | 2.2/√n秒 |
| 重炮 |伤害提升+穿墙 | 8秒 |
| 穿墙 |无视地形 | 8秒 |
| 地雷 |部署地雷(50伤害) | 18秒 |
| 巨型 |体型增大+50HP+20%伤害 | 10秒 |
| 散射 |三发扇形子弹 | 8秒 |
| EMP |摧毁护盾+减速3秒 | 瞬间 |

## AI系统

- **简单**：有LOS时追踪玩家，决策间隔1.0-1.8秒
- **普通**：LOS检测+躲避子弹+抢道具，决策间隔0.8-1.5秒
- **困难**：快速反应，主动躲避散射子弹，优先抢道具，决策间隔0.35-0.75秒

## 技术实现

```
index.html          入口
css/style.css       全屏自适应样式
js/
├── utils.js        常量、工具函数、CONFIG配置（20个可调参数）
├── audio.js        音效系统（Web Audio API）
├── input.js        键盘输入管理
├── maps.js         12张地图定义（水平镜像对称）
├── world.js        世界渲染（地形/砖墙/钢墙/水面/草地预计算）
├── particles.js    粒子特效系统（swap-and-pop优化）
├── powerup.js      道具系统（11种+地雷+applyPower）
├── bullet.js       子弹逻辑（角度支持散射）
├── ai.js           AI控制器（LOS/路径/躲避/道具搜寻）
├── tank.js         坦克逻辑（移动/开火/受伤/绘制）
├── game.js         游戏主循环、spawnAI、所有UI绘制
└── main.js         启动入口
```

### CONFIG 配置对象

游戏参数集中在 `utils.js` 的 `CONFIG` 对象中管理，调整平衡性只需修改一处：

```js
const CONFIG = {
  BULLET_HIT_RANGE: 26,        // 子弹碰撞判定范围
  POWERUP_PICKUP_RANGE: 34,    // 道具拾取范围
  POWERUP_DURATION: 8,         // 增益道具持续时间
  HEAL_AMOUNT: 40,             // 维修回血量
  MEGA_HP_BONUS: 50,           // 巨型额外血量
  MINE_DAMAGE: 50,             // 地雷伤害
  AI_DODGE_RANGE: 80,          // AI躲避子弹范围
  AI_SEEK_RANGE: 200,          // AI搜寻道具范围
  WIN_ROUNDS: 5,               // 胜利局数
  // ... 共20个参数
};
```

## 画布参数

- 逻辑分辨率：1600×900（16:9）
- 场地：22列×13行，格子55px，场地1210×715
- 场地水平居中，垂直偏上（留HUD空间）
- CSS `object-fit:contain` 自适应浏览器窗口
